# 第 11 层电梯视觉 H1 修复与定向验收报告

## 1. 结论

H1 假设成立：旧检测器在拟合平面前，先用相机光轴深度 `z` 围绕中位数裁剪。斜视同一门板时，门板两侧存在真实深度梯度，因而被误判为其他表面并删除，最终系统性压缩门板宽度。该宽度不是稳定的物理门宽，导致相同场景出现“失败—成功—失败”的抽签式注册。

最小修复已完成并通过一次有效 GUI 定向验收：完整有效轮廓先进入有界抽样的 SVD 平面拟合，再用既有平面残差内点剔除不同表面。`0.65 m` 最小宽度以及颜色、面积、深度、RMSE、竖直法向、最大距离、最大宽度和三帧一致性约束均未放宽。

有效仿真完成了电梯视觉注册、`TakeElevator(0->1)` 创建、开门、进厢、换层、出厢，并重新进入 1 层探索。尚未验证完整二层探索、`1->0` 返程电梯和主入口最终退出，因此第 11 层仍不能封口。

## 2. 根因与修复

旧流程：

1. 暗色轮廓内保留有效深度；
2. 计算中位深度；
3. 用 `abs(z-median) <= max(0.12, 0.08*median)` 裁剪；
4. 对剩余点做 SVD 和残差内点筛选；
5. 用切向投影跨度计算宽度。

当门板斜视约 40° 时，同一物理平面在光轴方向的深度跨度可超过步骤 3 的带宽。裁剪会保留门板中间窄条，删除两侧，造成宽度偏小。成功轮只在约 14° 的窄视角中采到恰好三帧超过 `0.65 m`，并非稳定识别。

新流程删除步骤 3。完整有效轮廓最多均匀抽样 5000 点做初始 SVD，再用 `max(0.02, 2.5*maximum_plane_rmse)` 的已有残差门限选内点并二次拟合。这样斜视门板的真实深度梯度由平面模型解释，门框和背景等不同表面仍由残差、RMSE、法向和尺寸约束拒绝。

## 3. 修改文件与行为

### `src/danger_search/danger_search/rgbd_door_detector.py`

- 移除 SVD 前的光轴中位深度带裁剪；
- 保留 5000 点有界抽样、两次 SVD、残差内点、RMSE 和法向约束；

## 5. 定位漂移结论

本轮离线真值结果：

- 总真实行程：`14.304 m`；
- 最大平面误差：`0.099 m`；
- 最终误差：`0.091 m`；
- P95：`0.090 m`；
- RMS：`0.061 m`；
- 最大 yaw 误差：`0.00263 rad`。

本轮没有复现此前约 `0.15..0.25 m` 的出厢一次性阶跃。电梯内约 `65..67 s` 出现 RGB-D 帧间 GICP 与 Livox scan-to-map 方向相反的大校正，但离线真值误差保持约 `0.05..0.09 m`，说明两者在本轮大体互相抵消，没有形成有害的全局跳变。

因此当前证据不支持立即用电梯地标重锚定 odom。任务层可以继续用新鲜电梯观测刷新等待点、穿门轴和出厢方向；若后续再次稳定复现定位阶跃，再考虑估计器层有限幅、带创新门限且同步清理局部地图窗口的地标校正。不能只改 MissionManager 位姿而不移动地图、轨迹和其他地标。
