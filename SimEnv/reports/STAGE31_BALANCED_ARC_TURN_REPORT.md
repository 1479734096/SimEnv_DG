# STAGE31 平衡弧线转弯与前向评分报告

## 目标

减少普通走廊拐弯和进出房间时的原地刹停、慢速拧转及重新起步顿挫，同时继续优先选择与当前航向一致的前沿，降低无收益调头。

## 实现

- 正式原地转向入口从 `0.90rad` 放宽到 `1.10rad`，普通中大角度拐弯可以继续执行 `v + omega` 弧线跟踪。
- 转向释放条件调整为航向误差不超过 `0.30rad`、实测角速度不超过 `0.30rad/s`，连续两个新鲜样本即可释放。
- 新增 `arc_turn_min_linear_fraction: 0.15`。它只抬高中等偏角的航向速度缩放，曲率、前向障碍和地面支撑安全门仍可继续降速直至零速。
- `min_linear_fraction: 0.35` 保持原有近直线语义，不把 35% 推进力扩散到大偏角。
- `turn_in_place_rate: 0.65rad/s` 保持不变；即使航向误差未达入口阈值，高速旋转仍会进入原地转向保护。
- `forward_alignment_weight` 已在正式配置中为 `0.80`，本阶段不重复改动评分尺度，仅增加配置回归断言。

## 兼容与安全

- `PathFollower` 和 `compute_tracking_command` 的新参数默认值为 `0.0`，未显式配置的测试或调用方保持旧速度曲线。
- 转向状态仍要求新鲜 yaw rate 才能释放；缺失、过期或非有限角速度会重置释放计数。
- 新增速度下限位于曲率和障碍缩放之前，不绕过 `GroundSupportSafetyGate`，也没有新增 `/cmd_vel` 发布入口。
- 门、电梯和危险源接近路径原有独立限速保持不变。

## 验证

- 单元测试覆盖正负 `1.09rad` 弧线推进、`1.10rad` 原地转向边界、两帧释放、无效 yaw rate 禁止释放以及曲率和近障优先限速。
- 正式配置测试固定平衡档参数，并固定 `forward_alignment_weight: 0.80`。
- 控制器、前沿、配置、运行时边界和命令归因定向回归：除既有时间预算断言外 `178 passed`。
- 完整 Python 套件：`883 passed, 1 failed`。唯一失败是 STAGE29 将 `floor_change_time_estimate` 调为 `50.0`，而既有 seed8127 断言仍要求 `>=70.0`；本阶段未覆盖该用户改动。
- 按既定安排，本阶段不运行双楼层 Gazebo 长测；后续长测应统计原地转向次数、持续时间、弧线最低速度、过冲和地面支撑拦截次数。
