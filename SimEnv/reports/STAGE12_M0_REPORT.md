# 第 12 层 M0 报告：定位漂移只读诊断

## 1. 结论

M0 已完成，可以进入 M2，但第 12 层整体尚未封口。本轮没有调整 GICP、尺度或
scan-to-map 的融合参数，只补充既有验收分支的只读结果元数据和低频结构化日志。

固定 `seed=42` 的第二轮 GUI 双层运行完整通过：主入口进入、电梯视觉注册、`0→1`、
二层探索、`1→0`、主入口退出、回起点和结果写出均成功。定位平移 RMSE 为
`0.089 m`，P95 为 `0.113 m`，最大/最终误差为 `0.316 m`，最大 yaw 误差为
`0.0027 rad`。误差不是静止积分发散，而主要出现在有运动的最后返航段。

M0 还确认了两个需要分开处理的机制：

- 深度数据新鲜时，最终两秒约 `0.237 m` 的 x 向误差增长中，scan-to-map 累计
  校正偏置变化约贡献 `0.137 m`，RGB-D 帧间平移相对真实运动少估约 `0.100 m`；
- Livox 尺度样本在转向/短窗口中可从 `0.793` 到 `2.146`，内部尺度一度达到
  `1.712`。该轮关键末段深度一直新鲜，因此尺度没有造成最终阶跃，但这是明确的
  后备链污染风险。

下一步 M2 应先约束 scan-to-map 的大校正和尺度更新条件；不得同时改两条链，也不得
引入电梯地标重置 odom、真值或固定场景坐标。

## 6. 最终误差阶跃证据链

最后返航段的离线误差在约两秒内由 `0.072 m` 增长到 `0.316 m`，主要为 x 方向。
同一窗口内 RGB-D 一直 fresh，因此 Livox 尺度没有进入融合输出。

定位节点已有周期日志可直接分解输出：`fused_position = depth_total +
depth_fusion_offset`。在仿真时间 165.354～167.362 秒：

- 融合 x：`0.172 -> 0.277 m`，变化 `+0.105 m`；
- RGB-D 累计 x：`0.373 -> 0.341 m`，变化 `-0.032 m`；
- scan-to-map 累计偏置 x：`-0.201 -> -0.064 m`，变化 `+0.137 m`；
- 离线 x 误差同期约增长 `0.237 m`。

由此可分解为：scan-to-map 的正向偏置变化贡献约 `0.137 m`；真实机器人同期仍有
约 `-0.132 m` 的 x 运动，而 RGB-D 只估计约 `-0.032 m`，少估约 `0.100 m`。两者
方向相同，合计解释该窗口的误差增长。该证据排除了“只有一个 0.25 m 校正尖峰”以及
“Livox 尺度直接造成末段误差”的简单假设。

## 9. 下一步与风险

M2 采用单机制、可回退顺序：

1. 先约束 scan-to-map：以本轮最大 `0.2276 m` 和末段累计偏置为证据，增加大校正
   的时序一致性/应用速率约束，并保证局部地图提交与实际应用量使用同一位姿；
2. 固定 seed 复跑，要求最大误差下降且完整双层不回归；
3. 再单独限制 Livox 尺度只在线性运动充分且转角有限的窗口更新；
4. RGB-D 少估若仍占主导，再根据真实 P99 单独评估帧间上限或运动先验，不能与前两项
   同时修改。

残余风险：第一轮主入口近场重观测仍有视觉时序波动；二层无前沿退让尚无真实触发证据；
正式比赛预算的覆盖率与识别率仍待后续整体回归。
