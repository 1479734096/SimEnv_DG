# 第 12 层 M3 报告：scan-to-map 质量诊断

## 1. 结论

M3 只读诊断链已经完成，并获得两轮固定 `seed=42` 双层 GUI 数据。诊断可以在同一
`/scan` 时间戳上反事实移除 scan-to-map 校正，分别计算 X/Y 轴校正收益，避免把相邻帧
RGB-D 里程计误差错误归因给地图校正。

两轮结果都表明 scan-to-map 整体仍有净收益，但当前没有找到可泛化的无真值标量质量量
来安全决定在线降权：对应点比例、残差分位、迭代次数和各向异性在合并样本上的 AUC
分离度只有约 `0.50～0.56`。残差中位数和正负比例达到 `0.69～0.85`，但它们带固定
世界坐标轴符号，容易过拟合本 seed、路径和墙面方向，不能直接转成生产门限。

因此本阶段没有实施质量降权、拒绝门或定位重锚定。M3 诊断子阶段可以封口，第 12 层
“定位漂移降低”尚不能封口。下一步若继续，应先设计旋转不变、方向一致的质量特征并用
不同 seed 复核；不能继续压统一校正幅值，也不能按本轮轴向符号写特例。

## 2. 改动文件与行为

- `imu_constrained_odometry.hpp`：只读暴露源点数、匹配/保留对应点数、迭代次数、
  残差 P50/P70/P90、均值/中位数/MAD、正负比例和二维协方差特征；匹配、验收、限幅、

  scan-to-map 和 2 秒运动一致性窗口；正式默认关闭时不累计新窗口状态。
- `scan_localization.launch`、`danger_search.launch`：增加默认 `false` 的诊断参数透传。
- `analyze_localization_quality_bag.py`：新增离线分析器，输出逐帧 CSV、2 秒窗口 CSV 和
  JSON 汇总；真值只在 bag 离线读取。
- `run_elevator_gui_test.sh`：显式诊断模式录制 `/scan` 和 `/rosout`，运行结束后自动生成
  质量产物；生产节点订阅审计保持不变。
- `test_imu_constrained_odometry.cpp`、`test_localization_quality_analyzer.py`：覆盖诊断字段、
  解析、同时间戳反事实、X/Y AUC 和非重叠误差窗口。

本轮未修改 GICP 参数、scan-to-map 校正权重、`0.10 m` 保护上限、地图更新语义、任务
状态机、控制器、官方环境或赛方说明。

## 3. 标签方法

对于时间戳 `t` 的已应用校正 `c`：

```text
error_post = odom(t) - truth_aligned(t)
error_without_map = error_post - c
benefit = |error_without_map| - |error_post|
```

X/Y 分量独立计算。只有该轴校正绝对值大于 `5 mm` 的帧参与 AUC，连续收益仍保留全部
数值。标签不使用相邻 odom 差分，因为相邻帧同时包含 RGB-D/Livox 里程计运动。

2 秒窗口使用同样的终点反事实，只把该窗口累计 scan-to-map 平移从终点位姿移除；同时
记录 RGB-D、Livox、命令积分、两里程计分歧、IMU 累计转角和深度新鲜率。

## 6. 两轮质量结论

合并后 X/Y 有效逐帧样本为 `802/878`。单帧校正平均净收益分别为
`+0.0078/+0.0026 m`；两轮各自的均值也都为正，证明不能把 scan-to-map 整体关闭。

| 特征 | X 合并 AUC 分离度 | Y 合并 AUC 分离度 | 判断 |
|---|---:|---:|---|
| 匹配对应点比例 | 0.507 | 0.505 | 无区分力 |
| 保留对应点比例 | 0.556 | 0.509 | 弱且轴间不一致 |
| 残差 P70 | 0.529 | 0.520 | 无法作门限 |
| 各向异性 | 0.523 | 0.549 | 无法作门限 |
| Livox-RGB-D 逐帧分歧 | 0.546 | 0.600 | 仅 Y 有弱信号 |
| 残差中位数 | 0.731 | 0.816 | 带坐标符号，不能直接泛化 |
| 残差正负比例 | 0.720～0.721 | 0.807 | 同上 |

2 秒窗口中，第一轮 Y 轴分歧 AUC 为 `0.895`，第二轮降为 `0.661`；样本仅
`31/35`，且轴向关系不稳定。它适合作为后续候选，不足以直接实现在线 alpha 降权。

两轮最大的误差增长窗口都集中在电梯跨层/出厢后的运动段，但 scan-to-map 在这些窗口
既出现最大有益校正，也出现有害校正。仅按运动阶段、转角或幅值统一抑制会再次产生 M2
的欠校正风险。

## 9. 残余风险

1. 两轮均未完成完整返程：第一轮物理倾倒，第二轮返程厅外路径耗尽；第 12 层不能据此
   宣称完整双层行为验收通过。
2. signed residual 的高 AUC 可能只是固定 seed 下的坐标方向标签泄漏；至少需要不同 seed
   和旋转不变特征才能进入生产。
3. `/scan` 使单轮诊断 bag 达到 308～378 MB，只能在显式诊断模式使用。
4. 逐帧日志由多个回调写到同一控制台时会交错；rosbag `/rosout` 消息本身保持独立，
   离线解析本轮对齐率超过 98%，但不应从重定向控制台逐行做严格统计。

## 10. 下一步最小实验

先独立处理第二轮稳定复现的返程 `elevator_trace_approach_exhausted`，不要把它混入定位
调参。定位侧只保留以下候选研究，不立即改生产：

1. 把校正与 Livox-RGB-D 分歧投影到机器人前向/侧向或局部结构主轴，消除世界 X/Y
   符号依赖；
2. 以跨 seed 离线 AUC、连续收益和任务回归共同筛选；
3. 只有旋转不变特征在至少两种 seed 上稳定分离，才实现单一、可关闭的 alpha 降权；
4. 拒绝/降权后仍必须用最终应用位姿更新地图并发布同一位姿，禁止双坐标系。
