# STAGE14.3 电梯语义地标漂移诊断报告

## 1. 阶段结论

本阶段完成了默认关闭、只读的电梯语义地标漂移诊断链，并按预注册条件运行了一次
`GUI=true`、`seed=8127` 定向 Gazebo。诊断准入失败，因此：

- 不实现定位校正；
- 不新增定位重置、位姿回写或地图重锚接口；
- 不运行第二轮同假设 Gazebo；
- 生产定位、地图、规划和控制行为保持不变；
- 诊断实现保留为默认关闭的证据工具，定位专项恢复为暂停。

失败不是因为“地标完全没有信息”。49 个确认样本中，最佳样本的地标残差与真值漂移
增量仅相差 `0.00241 m`，方向余弦为 `0.99996`。但是本轮没有复现预注册的
`>= 0.30 m` 高漂移窗口，也没有取得 `<= 0.15 m` 的低漂移负对照；所有确认样本的
向量误差中位数为 `0.22909 m`，说明门板中心在可见过程早段仍不稳定。该证据不足以
把地标残差安全地变成在线校正量。

## 2. 目标与冻结假设

待验证的单一假设是：每层电梯门在平面位置上具有相同的建筑语义位置，首次 0 层
RGB-D 电梯注册可作为固定锚点；后续楼层若在普通探索中再次看到同一关闭门板，其平面
残差可能直接反映定位平移漂移。

该假设只允许先做观察，不允许先改行为。冻结条件如下：

1. 只冻结首次有效的 0 层 RGB-D 电梯几何，运行期刷新不得覆盖；
2. 只在更高楼层、普通 `EXPLORE_FLOOR`、无换层 guard、建筑中只有一个公开电梯时观察；
3. 只接受关闭门板、宽度 `0.65～1.80 m`、距离不超过 `4.0 m`、与锚点 yaw
   差不超过 `0.35 rad`、宽度差不超过 `0.25 m` 的观测；
4. 连续 3 帧、相邻不超过 `0.4 s`、残差散布不超过 `0.15 m` 才确认；
5. 完整记录世界 X/Y 残差，并投影到门法向和切向；不只选择事后有利的单轴；
6. 离线准入要求高漂移复现、单候选身份、向量误差不超过 `0.15 m`、方向余弦不低于
   `0.90`、在任务后果前至少 `1.0 s` 确认，以及至少 10 个低漂移负对照且零误确认。

任一门槛不满足即停止，不降低阈值、不增加扫描、不强制停车等待地标，也不换 seed
补结果。

## 3. 实现

### 3.1 只读在线诊断

新增 `danger_search/landmark_drift_monitor.py`：

- 配置默认关闭；
- 冻结首个 0 层锚点且不可覆盖；
- 质量或上下文缺失时清空确认序列并回退到无诊断；
- 多候选时仅记录最近候选供分析，同时把候选总数写入证据，离线准入必须为单候选；
- 只返回诊断结构，不发布控制命令，不修改定位、地图或任务状态。

`MissionManager` 只在已有 RGB-D 门板检测和电梯几何注册位置接入该监视器，新增
`landmark_drift_anchor_frozen` 与 `landmark_drift_observation` 结构化日志。诊断结果
没有任何生产消费者。

### 3.2 离线真值评估

新增 `tools/offline/analyze_landmark_drift.py`：

- 读取生产任务日志中的合法传感器派生残差；
- 任务结束后读取独立诊断进程生成的漂移 CSV；
- 以锚点时刻的真值误差为原点，比较地标残差和真值漂移增量；
- 输出数量、分布、方向一致性、确认延迟、任务后果提前量及冻结门槛结果；
- 任一准入项失败时返回非零退出码。

真值只参与离线分析，不进入 `MissionManager`、定位节点、地图、规划或控制。

### 3.3 runner 与清理

`run_elevator_gui_test.sh` 新增显式
`ELEVATOR_TEST_LANDMARK_DRIFT_DIAGNOSTICS=1` 诊断开关。该开关要求同时录制定位和
独立离线真值，并只修改证据目录中的临时配置副本。

本轮结束后发现 FIFO 保活 shell 未被原有 TERM 清理。已把清理收敛为：

- TERM 后有界等待；
- 仍存活时对其独立进程组发送 KILL；
- `wait` 回收；
- 本轮明确遗留的 PID 已清理，最终 ROS master 端口和 ROS/Gazebo/控制器/任务进程为空。
