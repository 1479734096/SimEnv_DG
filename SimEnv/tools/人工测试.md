每轮流程
运行前：

git status --short
git rev-parse HEAD
git diff --check
python3 tools/offline/check_production_boundary.py
sha256sum -c OFFICIAL_FILES.sha256
ss -ltnp | rg ':11311\b' || true

运行结束后、启动下一 seed 前，立即把同轮文件归档，否则下一轮会覆盖：

cp results/danger_truth.json "$run_dir/danger_truth.json"
cp results/detected_danger.json "$run_dir/detected_danger.json"
sha256sum "$run_dir/danger_truth.json" \
        "$run_dir/detected_danger.json" > "$run_dir/result_files.sha256"

python3 src/building_obstacles/scripts/evaluate_danger.py \
--truth-file "$run_dir/danger_truth.json" \
--detected-file "$run_dir/detected_danger.json" \
--output-file "$run_dir/evaluation_result.json"

python3 tools/offline/analyze_mission_timing.py \
"$run_dir/mission.log" \
--auto-log "$run_dir/auto.log" \
--test-summary "$run_dir/TEST_SUMMARY.txt" \
--result-file "$run_dir/detected_danger.json" \
--evaluation-file "$run_dir/evaluation_result.json" \
> "$run_dir/mission_timing.json"

真值只能在任务进程结束后执行上述复制和评分，不能在运行期间读取。
