# 仿真测试操作指南

本文档整理多层（默认 3 层完整闭环）仿真的标准测试流程，包含**一键自动化测试（推荐）**与**双终端手动调试**两套方案。

```bash
source devel/setup.bash
```

## 方式一：一键全自动三层测试（推荐）

该方式由自动化 Runner 调度，自动按时序发送站立与 RL 控制指令、拉起算法、开启 4 项诊断录包，并在结束后自动执行离线真值漂移分析与归档。

### 1. 执行命令

- **极简模式（自动创建带时间戳的唯一证据目录，推荐）**：
  ```bash
  cd /home/xbh/tzb26/codeDG/SimEnv
  SEED=8127 tools/sim/run_elevator_gui_test.sh
  ```

- **指定归档目录模式**：
  ```bash
  cd /home/xbh/tzb26/codeDG/SimEnv
  SEED=8127 ELEVATOR_TEST_LOG_DIR=/home/xbh/tzb26/evidence/simenv/9.6.12.08 tools/sim/run_elevator_gui_test.sh
  ```

### 2. 自动化行为说明
- **环境**：默认 `FLOOR_COUNT=3`，`GUI=true`，仿真总预算 `1280.0` 秒，单层超时 `360.0` 秒，单层最小驻留 `60.0` 秒，墙钟总上限 `10800` 秒（3小时）。
- **流程**：底层环境就绪后，脚本自动注入按键 `2`（Fixed stand）并在 2 秒阻尼平息后自动注入 `6`（RL 模式），随后自动启动 `danger_search.launch`。
- **诊断**：站立前自动后台拉起完整漂移诊断包与全任务 RGB-D 诊断包（带 16GB / 2小时容量保护）。
- **闭环与归档**：持续监控 0→1→2 换层、2→0 返程及主入口退出。任务完成后自动安全停止所有进程，并自动调用离线脚本评估真值漂移与质量，写入证据目录中的 `TEST_SUMMARY.txt` 及对应 JSON/CSV。

## 方式二：多 Seed 连续批量测试（自动无头模式）

该方式用于无人值守连续测试多个 seed，默认无头模式（不弹 Gazebo GUI 窗口）运行更快速平稳；开启轻量真值与漂移评估，关闭耗费数十 GB 空间的 RGB-D 录包。单个 seed 失败不阻断，全部完成后自动输出结构化汇总报告。

### 1. 执行命令

- **默认 3 层无头连续跑多个 seed（推荐）**：
  ```bash
  cd /home/xbh/tzb26/codeDG/SimEnv
  tools/sim/run_multi_seed_test.sh 8127 1612 6946
  ```

- **指定 2 层、开启 GUI 连续测试**：
  ```bash
  cd /home/xbh/tzb26/codeDG/SimEnv
  tools/sim/run_multi_seed_test.sh -f 2 --gui 8127 1612
  ```

- **自定义批次输出根目录**：
  ```bash
  cd /home/xbh/tzb26/codeDG/SimEnv
  tools/sim/run_multi_seed_test.sh -o /home/xbh/tzb26/evidence/simenv/batch_custom 8127 1612
  ```

### 2. 自动化产物
批次运行结束后，将在输出根目录生成 `BATCH_SUMMARY.md` 并在终端打印结果表格，汇总每个 seed 的成败状态、耗时、客观得分（正确/总数）及定位最大/最终漂移。

## 方式三：双终端人工分步调试

用于需要精细排查各阶段控制流、可视化点云或单步定位状态的调试场景。

### 步骤 1：终端 1 启动仿真环境与控制器
```bash
cd /home/xbh/tzb26/codeDG/SimEnv
source devel/setup.bash
SEED=8127 FLOOR_COUNT=3 GUI=true ./auto.sh
```
- 等待 Gazebo 物理与 12 路关节状态就绪；
- 在控制台交互提示时输入 `2`（Fixed stand 固定站立），观察四足平息着地冲击 2 秒；
- 紧接着在控制台输入 `6`（切换进入 RL /cmd_vel 模式）。

### 步骤 2：终端 2 启动生产任务节点
```bash
cd /home/xbh/tzb26/codeDG/SimEnv
source devel/setup.bash
roslaunch danger_search danger_search.launch controller_ready_ack:=true
```

### 步骤 3：终端 3 启动可视化（可选）
```bash
cd /home/xbh/tzb26/codeDG/SimEnv
source devel/setup.bash
rviz -d src/danger_search/config/elevator_baseline.rviz __name:=elevator_test_rviz
```

### 步骤 4：人工测试结束后的证据归档与评分
任务完成后（或手动 Ctrl-C 终止后），运行以下脚本归档并读取评分：
```bash
run_dir="/home/xbh/tzb26/evidence/simenv/seed8127_manual_$(date +%Y%m%d_%H%M%S)"
mkdir -p "$run_dir"

cp results/danger_truth.json "$run_dir/danger_truth.json"
cp results/detected_danger.json "$run_dir/detected_danger.json"
sha256sum "$run_dir/danger_truth.json" "$run_dir/detected_danger.json" > "$run_dir/result_files.sha256"

python3 src/building_obstacles/scripts/evaluate_danger.py \
  --truth-file "$run_dir/danger_truth.json" \
  --detected-file "$run_dir/detected_danger.json" \
  --output-file "$run_dir/evaluation_result.json"

python3 tools/offline/analyze_mission_timing.py \
  logs/mission.log \
  --auto-log logs/auto.log \
  --result-file "$run_dir/detected_danger.json" \
  --evaluation-file "$run_dir/evaluation_result.json" \
  > "$run_dir/mission_timing.json"
```

## 关键观察与核验要点

1. **姿态与站立**：从 Fixed stand（2）切入 RL 模式（6）期间，四足着地冲击是否平息，机器人是否平稳起步。
2. **点云与走廊**：走廊两侧墙体点云是否贴合真实墙面网格，走廊中央无虚假前沿或重影障碍。
3. **电梯视觉注册与换层**：
   - 0 层是否成功确认电梯门候选并完成视觉竖井几何注册；
   - 依次完成 0→1 换层、1→2 换层；
   - 到达 2 层后完成探索，启动 2→0 返程电梯；
   - 走出 0 层轿厢并最终完成主入口返航退出。
4. **输出产物**：检查 `results/detected_danger.json` 是否包含已发现目标并成功写出。
