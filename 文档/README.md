## 证据口径

- 设计目标、软件实现说明和测试结果必须分开表述。
- 当前源稿中的“【待填写】”仅用于待补的项目成员信息、正式测试数据和图像证据，不代表
  已完成或通过。
- 危险源坐标、覆盖率、检出率、虚警率和任务用时应由可追溯的正式测试日志或结果文件填入。
- 真值、完整 world 和布局元数据仅允许在任务结束后的离线评估中读取，正式算法不得使用。
